# Reference data

Independent figures used **only to check** the generated maps (see `docs/accuracy.md`). They are never used to draw geometry.

| File | Content | Source |
| --- | --- | --- |
| `governorate-areas.csv` | Published surface area of each governorate (km²) | Ministry of Industry (tunisieindustrie.nat.tn, archived 2014) as compiled in the English Wikipedia article [Governorates of Tunisia](https://en.wikipedia.org/wiki/Governorates_of_Tunisia) |

Published areas include inland water bodies (sebkhas, lagoons) and come from older surveys, so differences of a few percent are expected for some governorates.
